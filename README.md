# Data Science Learning Journey

Learning path: Statistics → Machine Learning → Research Applications

## Week 1: Python Libraries & SQL Fundamentals

**Goal:** Master core tools for data analysis

### Files:
- `numpy_basics.py` - Arrays, operations, CSV loading
- `pandas_basics.py` - DataFrames, filtering, grouping, multiple CSVs
- `matplotlib_basics.py` - Visualizations (line, scatter, histogram)
- `scipy_stats_basics.py` - Distributions and probability
- `sql_basics.py` - SQLite queries (SELECT, WHERE, GROUP BY)

### Data:
- `data/batteries.csv` - Sample battery degradation data
- `data/batteries.db` - SQLite database

### Output:
- `output/plots/` - Generated visualizations
- `output/*.csv` - Results and aggregations
- `output/*.txt` - Analysis results

### How to run:
```bash
python Week1_Python_SQL/numpy_basics.py
python Week1_Python_SQL/pandas_basics.py
python Week1_Python_SQL/matplotlib_basics.py
python Week1_Python_SQL/scipy_stats_basics.py
python Week1_Python_SQL/sql_basics.py
```

### Learning highlights:
- Created 5 CSV files from multiple sources
- Loaded and combined datasets using Pandas
- Generated 3 different plot types
- Calculated statistical distributions
- Queried data using SQL (4 different queries)
